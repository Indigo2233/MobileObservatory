# Security policy

## Supported versions

Security fixes target the latest released version and the current `main` branch.
Older APKs may require upgrading before a fix can be applied.

## Reporting a vulnerability

Use GitHub private vulnerability reporting from the repository Security page. If
that option is unavailable, contact the maintainer through the repository owner's
GitHub profile and request a private reporting channel.

Include affected version or commit, Android version, device class, reproduction
steps, impact, and any proposed mitigation. Remove credentials, exact observing
locations, device serial numbers, and unrelated logs.

Do not create a public issue for vulnerabilities involving arbitrary code execution,
USB device impersonation, unsafe mount motion, credential exposure, malicious image
or catalog parsing, signature bypass, or release-key compromise.

The maintainer will acknowledge a complete report, assess affected versions, and
coordinate disclosure after a fix or documented mitigation is available.
