# 实时行星叠加的科学边界

`LivePlanetaryEngine` 使用实时流的单遍筛选、行星相关配准和线性累积，与离线行星录像的“两遍分析后选全片最佳帧”分开。

- 先排除低信号、过曝、噪声和越出画面的帧。默认在最近 64 张质量有效帧（包含当前帧）的分数窗口内取最高 50% 对应阈值，低于阈值的新帧拒收；分数并列时可能收超过 50%，已收的历史贡献不会被撤回。窗口只存分数，不缓存一段录像。
- 默认先在前 3 张质量有效帧中选择最清晰的参考；等待期间提示“正在选择参考帧”。仅复用一份私有候选像素缓存，前两张启动帧不会计入叠加贡献或累计曝光。参考只提供坐标，随后仍逐帧判断当前输入是否合格并累计当前输入，不能把候选参考的曝光偷换成当前帧曝光。参考确定后固定，复用全局亚像素相关配准、可选多对齐点局部位移、折叠网格与边缘残差拒收。
- 若启动期间全部画面都模糊，随后更清晰且全局相关度至少 0.9 的画面连续 3 次因边缘残差拒收，则进入需要重新开始的状态，显示“参考帧与当前图像不一致，请清空后重新开始”。旧快照、覆盖与曝光计数保留到用户明确清空；不会放宽边缘门限、自动重锚或把新参考坐标混进旧累积。质量改善阈值为参考分数的 1.15 倍，其他拒收或正常收帧会中断此诊断；它是可恢复的参考不一致提示，不是对所有参考问题的自动识别。
- 原始线性 mono/RGB 图像进入解算；复用一张来源亮度缓存和两张位移网格，双精度累积、逐像素覆盖计数。无插值支持的边缘不增加权重；三色通道共用覆盖。预览拉伸、颜色显示或锐化不写入科学累积。
- 输出不进行行星自转/视场旋转校正，也不锐化。长时间累积可能因行星自转或光学状态变化损失细节，应按目标与设备条件重新开始；具体时长需实拍判断。
- 上限与离线行星原语一致：单帧最多 4 MP，最多 10,000,000 张累积贡献。预分配门禁独立估算累积、一份启动候选、参考/来源平面、原始队列、最多三份瞬时快照、解码/显示 scratch 与位移网格；不按帧数增长内存。实际分辨率或通道变更拒收，不混入原堆栈。默认启动窗口为 3 张，科学原语允许显式设置 1–16 张，应用使用默认值。
- 重置/关闭的取消可在行扫描、配准搜索及累积期间响应；部分写入的引擎整体丢弃。之前发布的快照独立拥有像素和权重，继续有效。快照记录在线策略、窗口阈值、参考质量、配准方式、拒收计数、有效曝光及预算；不存在像素 RMS 或旋转拟合时明确标记不可用。

新增合成回归覆盖已知亚像素位移相对直接平均的改善、局部畸变细节、在线模糊筛选及历史贡献保留、无效画面/超范围位移拒收、RGB 比例/曝光/快照独立性、累积中取消与资源预算。默认参数另覆盖“首张重模糊、接着清晰帧”的恢复，启动候选的私有所有权和真实贡献曝光，以及坏参考提示后保留旧坐标、快照和统计直至明确重置。引擎 10 项数值测试已通过，Android 实际协调器启动/导出与切换也通过，完整证据见 [本轮更新](STACKING_AND_SKY_INTERACTION_UPDATE.md)；没有据此宣称设备帧率、功耗或实拍精度。
