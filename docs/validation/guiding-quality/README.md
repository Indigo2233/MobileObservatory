# 导星通量历史与图像诊断（2026-10-27）

应用基线：`f073e0cac96e0420cd0b8f6fb72990de42617a5d`。
PHD2 固定参考：`70e9fd178b3122b6553646c60f462cb09335dcc5`。

## 通量与丢帧

移植 `guider_multistar.cpp::MassChecker`：默认 45 秒历史、至少五个历史样本、
偶数样本使用上中位数、默认 50% 容差。记录历史中位数的高/低水位，低水位以 5%
速率跟随中位数恢复，并单独判断低通量背景中的突增。拒绝的通量仍进入历史，以便持续
天空变化可以更新统计。手动曝光变化重置历史；核心保留并验证自动曝光的通量归一化，
当前应用接入手动曝光。

历史采用可复用的 LongArray/DoubleArray 环形队列，中位数使用原生类型缓冲区上的
选择算法。每帧只复制有效历史样本，避免历史条目对象、装箱和整段排序。Android
使用单调毫秒时钟代替上游 UTC 时钟，避免系统时间校正改变历史窗口。

正常导星需要存在当前帧有效主星，主星丢失时辅助星独立驱动修正的路径已关闭。
质量异常帧继续停发修正，保留滤波历史和 PPEC 模型；主星搜索锚点维持上一次认可的
位置。明确停止、重新选星、重新启动及相机设置变更按既有生命周期清理相关状态。
PHD2 的推算盲导、完整 DistanceChecker 恢复和跨停止/暂停的 GP 保留条件继续单列。

`scripts/Generate-Phd2MassReference.py` 从 Git 对象提取完整、未修改的 MassChecker
类，替换毫秒时钟后编译 C++，生成 1,786 组参考。覆盖阈值边界、云层下降与恢复、
高水位以下的突增、手动/自动曝光切换、缺帧、45 秒边界及高频环形历史。
Kotlin 拒绝结果一致，四项数值限制在 1e-10 容差内一致。资源与源码哈希在
`app/src/test/resources/guide/phd2-mass-reference.json`。

回归同时覆盖拒绝帧后 Hysteresis 历史、真实原生 PPEC 模型保留，以及实拍 IMX585
图像减为三分之一亮度时拒绝修正、保持主星锚点、恢复清晰图像后重新测量。

## 原始图像诊断性能

原始 HFR、能量分布、横纵剖面与 PHD2 导星 HFD 继续分别保留现有数值口径。
原始诊断使用原生类型像素/通量缓冲区，稳定排序以半径位表示和原始样本顺序编码，
能量分布采用累计统计。像素只读取一次，每颗星的诊断直接使用 RAW 访问器，
帧的 CFA 解释和饱和值在分析入口统一取得。

与基线完整输出的逐浮点位校验覆盖 288 组：MONO8、Bayer8/14、MONO16、RGB24/48，
三种星像宽度、四种亮度及四种位置，包括饱和、暗背景和边缘。校验包含像素切片、
HFR、通量、背景、峰值、饱和标志及全部曲线数据；前后校验一致。

桌面 Kotlin 1.9.22 CLI / JDK 21，RAW14 模拟场、20 颗星、预热 30 次后测量 21 次。
计时包含 20 份剖面计算和完整输出消费，排除帧生成、采集和预览渲染。
