## 参考链路

PHD2 在支持的 Bayer RAW 路径上执行 `QuickLRecon`，以滑动 2×2 窗口的整数均值生成
同尺寸亮度图；末行/末列使用两个样本，右下角保留原值。采样窗口中心相对输出数组索引
为 (+0.5,+0.5)。本应用对公开星点坐标补回该常量，以保留原始传感器图像、点击与标记的坐标约定。
校准与导星误差的单位维持原始导星像素。

`Star::Find(FIND_CENTROID)` 使用 3×3 平滑定位峰值；在 7–12 px 环带上最多进行九轮
2σ 背景剔除；在半径 7 px 圆孔内选取高于背景 +3σ 的样本，以扣除背景的通量计算质心、
星体质量与 HFD。SNR 沿用上游的总通量、背景方差和标称 0.5 e⁻/ADU 公式，
此数值口径用于算法权重，并未使用逐型号实测增益标定。

实现按访问位置重建像素，局部测量复用覆盖峰值搜索区和背景环带的小块缓存；默认搜索
半径 3 px 时为 31×31 个整数，约 3.8 KiB，缓存硬上限为 16 KiB。RAW 候选筛选另用
两行布尔数组，4K 宽度约 7.5 KiB。缓存容量随测量窗口确定。
原始采集字节保持不变。只有仍含 CFA 的输入进入亮度重建，已确认的 SDK 合并单色输出直接测量。
原始各通道的裁切检查继续保留；亮度平均后峰值下降仍可检测原始通道饱和。

星体测量采用默认 HFD 1.5–20 px、跟踪 SNR ≥3，自动选星 SNR ≥6，并优先选择低于
90% 饱和值的有效星。已有二阶半径及原始饱和门控继续生效。已选星具有独立局部测量入口，
可绕过全图候选阈值。原始 HFR、剖面 ADU 和能量诊断继续直接读取传感器样本。

## 按需重建与候选筛选

2026-10-27 在 `ca02781` 的测量核心上增加 RAW 保守预筛选。全图仍执行 RAW 扫描；
QLR 仅用于稀疏背景采样、通过筛选的候选位置、相邻峰值比较及星体局部测量。
默认每隔 8 px 采样背景，局部测量覆盖峰值搜索范围及半径 12 px 的背景环带。
每个重建像素继续遵循完整图像的邻域和末行/末列规则；局部缓存边界保持原图坐标。

令全图亮度阈值为 T，四种 CFA 相位背景均值向下取整为 b[i]，
各相位 RAW 阈值为 `b[i] + floor(T) - floor(sum(b)/4)`。四个 RAW 阈值的总和为
`4*floor(T) + r`，其中 r 在 0..3。一个 QLR 像素大于 T 时，其四个输入之和至少为
`4*(floor(T)+1)`，因此至少一个输入超过对应 RAW 阈值。这保证预筛选保留全部原有
亮度超阈值位置，最终峰值、质心、SNR、HFD 继续使用精确 QLR 样本。

新增验证覆盖 RAW8/14/16 阈值边界、偏色天空背景、全平背景、彩色弱星与全图重建
结果一致性，以及 4096 px 宽图像上的 C++ 参考与缓存复用。完整 AutoFind 和局部跟踪/
重获策略继续单列。

20 颗星，完整检测上限 16 颗。
