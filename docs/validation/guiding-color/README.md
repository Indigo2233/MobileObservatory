## 参考链路

PHD2 在支持的 Bayer RAW 路径上执行 `QuickLRecon`，以滑动 2×2 窗口的整数均值生成
同尺寸亮度图；末行/末列使用两个样本，右下角保留原值。采样窗口中心相对输出数组索引
为 (+0.5,+0.5)。本应用对公开星点坐标补回该常量，以保留原始传感器图像、点击与标记的坐标约定。
校准与导星误差的单位维持原始导星像素。

`Star::Find(FIND_CENTROID)` 使用 3×3 平滑定位峰值；在 7–12 px 环带上最多进行九轮
2σ 背景剔除；在半径 7 px 圆孔内选取高于背景 +3σ 的样本，以扣除背景的通量计算质心、
星体质量与 HFD。SNR 沿用上游的总通量、背景方差和标称 0.5 e⁻/ADU 公式，
此数值口径用于算法权重，并未使用逐型号实测增益标定。

实现采用最多 32 行的缓存；4K 宽图像需要约 256 KiB 缓存，避免增加完整高位深传感器图像。
原始采集字节保持不变。只有仍含 CFA 的输入进入亮度重建，已确认的 SDK 合并单色输出直接测量。
原始各通道的裁切检查继续保留；亮度平均后峰值下降仍可检测原始通道饱和。

星体测量采用默认 HFD 1.5–20 px、跟踪 SNR ≥3，自动选星 SNR ≥6，并优先选择低于
90% 饱和值的有效星。已有二阶半径及原始饱和门控继续生效。已选星具有独立局部测量入口，
可绕过全图候选阈值。原始 HFR、剖面 ADU 和能量诊断继续直接读取传感器样本。

## 数值与误差

`scripts/Generate-Phd2StarReference.py` 编译原始 `QuickLRecon`、`hfr`、`Star::Find` 函数体。
替代部分限于 wx 容器、图像分配、日志及状态容器，不导入 Android 实现。
82 组参考包含边界尺寸、8/14/16 位、局部背景离群点、空图、热像素、平顶饱和与 64 组 CFA 位相扫描。
Kotlin 测量核心与 C++ 的坐标、SNR、HFD 在 1e-10 容差内一致，质量在 1e-8 内一致。
公开 Float 坐标与 SNR 使用相应的 Float 精度容差。

下表为偏色模拟星像的传感器坐标误差 RMS。R/G/G/B 响应为 4/0.4/0.4/0.08，
每个宽度扫描八个亚像素位置；输入为 RAW14、无随机噪声、无截幅。数据用于受控算法比较。

| Gaussian σ（px） | 原实现 RMS（px） | 对齐后 RMS（px） |
|---:|---:|---:|
| 0.8 | 0.34513 | 0.14374 |
| 1.2 | 0.24084 | 0.00587 |
| 1.8 | 0.09079 | 0.00309 |
| 2.5 | 0.03576 | 0.03977 |

结果随采样和星像宽度变化。欠采样的偏色星仍有位相误差，宽星像受到固定孔径和环带的影响；
本组宽星像中原实现的误差略低。亮度重建还会平滑图像，因此原始诊断继续保留。

IMX585 实拍星场使用原有固定 CFA 格点平移、校准、脉冲与闭环求解器回放；七种算法的
最后 30 周期 RMS 分别为 Hysteresis 0.1185、Identity 0.0573、Lowpass 0.1251、
Lowpass2 0.2492、PPEC 0.1037、ResistSwitch 0.1216、Z-filter 0.1784 px。
这些属于受控图像回放，实际器材、色彩响应、云层及机械扰动继续现场验收。

`baseline-*.csv` 为修改前生产检测器结果，`aligned-*.csv` 为对齐后结果。
`provenance.json` 记录基线、参考提交、输入参考包哈希及回放数值。
