# 指向相机与主镜校准：统一流程

2026-10-14，实施前核对 `main` / `5e1c136`。本文件落实用户关于手机支架、辅助相机和坐标关系的要求，承接 [观测流程](OBSERVING_WORKFLOW_DESIGN.md)、[坐标与校准](PHONE_PLATE_SOLVE_PLAN.md)及 [交互规范](INTERACTION_GUIDELINES.md)。实现和自动化证据在末节逐项记录；真实夜间精度与器材运动验收另记，不能由页面存在或合成样本代替。

## 1. 要解决的问题

原实现已经能计算刚性非同轴关系：手机通过亮星或主镜相机取得参考，辅助相机也有同类采样、验证和保存。但两者是独立页面，辅助路径藏在手机向导的“其他方式”；支架只有“已锁紧”勾选。用户看不出手机与主镜关系、可调支架怎样处理，以及不同坐标代表谁。

统一为一个任务：**指向相机与主镜校准**。手机具体摄像头和导星/寻星镜上的辅助相机是两种指向来源，使用同一组主镜参考、安装选择、采样进度、独立验证、保存和结果摘要。相机焦距影响视场与解析条件，不决定另一套导航层级；设备驱动、手机 Camera2/IMU 与辅助 USB 采集仍分别负责自己的数据。

主入口为 **星图 → 观测准备 → 指向校准**；推镜发现缺少关系时打开同一任务。既有辅助校准快捷入口也进入同一任务并预选辅助相机，返回实际来源，不创建第二份校准状态。首屏只有三组容易理解的选择，标题使用“用哪台相机定位”“主镜参考”“支架状态”，然后给一个下一步。曝光/RAW 格式、反射镜、跟踪、人工居中误差与坐标详情默认折叠在高级菜单或省略号里。缺光路配置、星表、权限或连接时，只显示一条短提示和就地恢复入口，不把诊断和教程铺满页面。

## 2. 三个选择决定可走的路径

| 选择 | 界面内容 | 决定什么 |
|---|---|---|
| 指向相机 | 手机 / 辅助相机；手机显示具体物理摄像头，辅助显示当前连接设备及导星/寻星光路 | 哪个相机负责测得自身天球姿态，哪些拍摄与定位参数适用 |
| 主镜参考 | 目镜 / 主镜相机 | 用户亮星居中给出主镜轴，或主镜独立解算给出轴与可用像面转角 |
| 安装方式 | 固定 / 可调后锁紧 / 无法固定 | 是否允许建立并复用该相机到主镜的刚性关系，是否提供可选同轴调整 |

只询问软件不能推断的物理关系。主镜或辅助相机已经连接时自动带入设备身份；连接角色不能自动证明其装在正确光路上。切换手机物理镜头、辅助设备或主镜参考后，丢弃与新选择不相容的任务草稿；历史关系保留身份和失效原因，不拿旧样本拼接新关系。

| 安装状态 | 首屏动作 | 允许保存什么 |
|---|---|---|
| 固定 | 确认安装稳定且能看见天空 → 开始校准 | 独立验证通过的固定关系，同轴并非要求 |
| 可调后锁紧 | 可直接锁紧开始；也可先“调整同轴”再锁紧校准 | 锁紧后重新采样并独立验证的关系 |
| 无法固定 | 短提示“固定后才能校准镜筒”；返回使用已有星图手机浏览/相机定位 | 不保存固定关系，不由相机自身方向宣称镜筒到位 |

确认锁紧表示用户确认安装稳定，不表示软件检测到了松动。相机随整个镜筒一起转动不改变安装关系；相机相对镜筒松动、重新调节或拆装则只让相关关系失效。

## 3. 不强制同轴，调整同轴只是可选准备

固定安装即使偏离主镜很多，也可以用实际相机姿态与主镜参考求出主镜轴在该相机坐标中的方向。两相机无需拍到相同星场，前提是各自都能取得同一天球参考系下、时间与稳定性合格的观测。无法调到同轴仍可继续校准；使用范围内要能持续看见天空。

可调支架的“调整同轴”使用真实配对采样，主层只显示两轴的 **偏角**，让用户通过重测观察数值是否趋近零；**水平/竖直偏差**和不确定度在“测量详情”展开。这些分量属于经过镜面奇偶性归一化的相机光学坐标，不能直接假定为手机屏幕左右上下，更不能指示未知机构应拧哪颗螺丝或向哪个方向旋转。

1. 进入调整时，明确相机安装将变化，撤销该来源的旧固定关系和当前镜筒推算；其他独立光路不变。
2. 目镜路径选亮星并确认主镜居中；主镜相机路径取得独立解析参考。停稳后测一次偏差。
3. 用户调节后重新停稳、重新测量；未取得新样本时不把旧数字显示成当前位置。
4. 锁紧后离开调整，重新开始正常校准，换方向独立验证通过才保存。

粗调样本不进入标定训练/验证集合；粗调角距不是标定残差。不会用预设数字、磁罗盘方向或屏幕十字线位置显示“已同轴”“已校准”。白天有限距离目标可能有视差，本任务的天球测量不能由白天粗调代替。

## 4. 同一套采样、验证和保存

| 主镜参考 | 第一次配对 | 另一个方向的独立验证 |
|---|---|---|
| 目镜 | 选择可见亮星，主镜居中确认与指向相机拍摄/解析配对 | 选择另一颗满足分离要求的亮星，重新居中并重新拍摄，不沿用第一次曝光 |
| 主镜相机 | 指向相机和主镜各自采集、解算并检查时间与稳定性 | 手动换方向再配对；满足 GOTO 条件时可选自动移动采样 |

手机来源保留物理镜头、实际内参/裁切、定时、星野姿态与可用 IMU；辅助来源保留 USB 设备/光路、原始位深/格式、参考像素、保守曝光时间范围及光学稳定性证据。用户只看到同一进度和当前适用的恢复动作；两种来源不需要相同采集设置，也不能为统一 UI 放宽各自的科学条件。

初始轴关系只需一组有效配对，另一方向用于独立验证。正常模式沿用现有两组流程；手机镜面 IMU 传播沿用三组 hand-eye 训练加第四组独立验证，不因页面合并而减少约束。辅助相机不要求手机权限、手机固定或 IMU；正在导星、录像、设备写设置、另一科学采集或运动未结束时，按既有所有权规则等待或给出恢复入口，不能暗中抢设备。

失败或取消不覆盖旧的有效关系；换源、移位或参考光路改变后不能保存旧草稿。保存重新检查两端设备身份、安装/光学版本、原始观测 ID、独立性、几何、时钟和误差预算，包含证据的关系原子写入仓库。当前方向与“已到位”不从旧持久化结果直接恢复。

## 5. 结果要说清校准了谁

默认关系摘要只显示所选相机及具体镜头/设备 **→ 主镜**与有效状态；采样完成页给保存、继续观测，失效时给“安装移动了，重新校准”。完成页保留一行独立验证误差；安装方式由设置页带入，不同轴偏差、**镜筒方向**或 **镜筒方向与像面转角**模型及坐标放在可展开详情。校准进行时只显示本步目的和必要反馈，不让新手先理解偏置、转角或矩阵才能继续。

目镜亮星只约束镜筒轴方向，不能给主镜像面绕轴转角。有效主镜完整 WCS 可提供完整旋转关系，但此处仍是方向/姿态标定，未估计相机之间的三维平移，不称作完整六自由度外参。

在采样/结果详细层区分坐标，而不是堆成默认说明：

| 显示对象 | 标签与依据 | 禁止推导 |
|---|---|---|
| 指向相机 | 相机实测，详情显示手机镜头或辅助设备身份、拍摄时间与配对误差预算 | 未标定时标成主镜坐标 |
| 主镜 | 亮星居中/主镜相机实测；后续由有效关系推算时明确“关系推算” | 默认等于手机中心、辅助相机中心或任意 ROI 中心 |
| 架台 | 架台回报，保留原始 JNOW 标签；可读能力在高级设置显示，不伪造协议没有的采样时刻 | 作为独立光学真值或证明同轴/标定准确 |
| 目标（原推镜任务） | 所选目标及坐标历元；本校准详情不重复目标卡 | 作为当前实际位置或完成依据 |

原始解析、推算方向、目标和架台回报分别保留。每行明确坐标历元和角度单位：光学结果为 J2000，架台原始回报为 JNOW，不能直接当作同一时刻的误差比较。光学详情保留真实拍摄时间，不因打开页面、重算关系或 IMU 传播刷新绝对定位时间。

## 6. 架台按能力增加动作

无架台也能完成手机/辅助相机与主镜校准。只读坐标可供对照；不能启用 GOTO/SYNC。双相机参考、参考能力与源可用、架台具有 GOTO 且空闲时，手机和辅助相机都可以使用同一自动移动采样任务；开始前展示移动计划并由用户明确启动，所有步骤使用既有运动 owner 和 STOP，每次移动前重检条件。

本校准任务建立相机到主镜关系，不自动 SYNC。**验证指向、同步赤道仪、移动到目标**是不同动作：验证不写回；同步要求独立光学参考和实际 SYNC 能力；GOTO 要求实际运动能力。既有“指向并居中”若包含 SYNC，在任务开始时说明运动与写回行为。刚写回后的坐标回读不能成为同一输入的独立验证。

编码器辅助必须依据实际协议暴露的轴读数语义、时间和模型版本。当前仅有位置计数器或型号名不能宣传“绝对码盘矫正手机”；这次统一校准页面不新增未验证的编码器融合。
