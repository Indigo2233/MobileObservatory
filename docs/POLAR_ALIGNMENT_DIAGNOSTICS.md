# 三点极轴采样与失败诊断

## 2026-10-25 现场反馈

用户提供的日志记录了主相机 USB 断开重连、停止和恢复采集，以及 5 秒曝光下多次 Player One `OPERATION_FAILED` / error 16。SDK 的 error 16 对应操作失败；日志没有保存极轴流程阶段、ASTAP 输出或图像，无法据此确定每次失败的具体环节，也无法还原失败照片。

代码中另有可独立复现的问题：已连接相机在极轴页的传感器预设高度为零，流程却在取得实际图像前校验视场；有效焦距和像元仍可能被判为信息不足。异常仅显示在长页面底部，采样卡没有原图查看或完整解算日志入口。停止按钮改变界面状态后，原协程仍可能继续执行；转轴等待超时也未阻止后续采样。

## 实施范围

- `PolarSampleSession` 负责每点的采集、实际图像视场检查、解算、失败与取消状态。图像在光学检查和解算前登记；已拍摄但解算失败的图像、原始输出和时间保留在任务状态中。
- `PolarSamplesViewModel` 保留采样记录，查看原图再返回和 Activity 重建后仍可检查。图像位于应用缓存，进程恢复和长期归档尚未作为持久化能力交付；系统可能清理缓存。
- 位置、光学与高级设置折叠，执行时收起；曝光、试拍和流程操作在高级设置之前。横屏并列图像与控制区，竖屏上方常驻图像，控制区独立滚动。
- 采样图在解算开始前交付主预览，失败时保留图像。全屏检查在当前页对话框中复用 `MediaImageInspection`，支持缩放、区域 1:1 与显示直方图；打开、关闭检查窗口保持解算继续运行。图像使用 UInt16 预处理和受限区域读取。试拍图、三个采样点和调整图像按最近事件显示；检查中的图像固定，关闭后返回最新图像。
- 每点提供查看图像、重新解算、选择文件，以及失败后的无架台提示解算；重拍只开放当前采样位置，避免将新轴姿态混入旧点。诊断可展开、选择和复制。无新图像的采集失败明确显示尚未取得图像。
- 每次执行冻结光学参数和搜索策略，视场按实际图像高度、合并倍率、焦距和像元确定。关闭架台提示时使用全天搜索，避免未对准的架台坐标限制搜索区域。
- 失败点重试保留先前成功点；已经完成的转轴不重复执行。转轴被中断、旧点被替换或位置关系不再可靠时，重新开始一组采样。手动挪动架台、改变相机安装或更换设备后应主动重新开始。
- `PolarWorkflowTask` 统一持有采样和解算协程。停止、全局 STOP、返回及离开前台会取消后续拍摄和转轴；ASTAP 沿用可取消的进程等待与退出清理。转轴未启动或超时报告失败，阻止继续采样。
- 拍摄入口在需要时恢复采集；曝光等待预算按曝光时长计算，等待期间检查断线、暂停和参数变化，并跳过可能在请求前开始的曝光。超时显示等待时长、曝光和最近 SDK 报告。
- 日志增加 `PolarAlign` 与 `PolarCapture` 记录，包含启动参数、每点阶段、图像路径、画幅、曝光、失败及 ASTAP 输出。相机 SDK 和冻结的原生库保持既有版本。

## 曝光、试拍与当前失败

- 极轴页按秒输入曝光，提供常用时间，并按相机单帧曝光范围校验。试拍、自动三点采样、单点重拍和连续调整都将本次曝光传给相机；拍摄入口在设置锁内停止旧采集、写入 SDK、恢复采集，再等待完整新曝光，FITS 写入实际曝光读数。运行中先停止，再调整曝光。修改曝光前检查录制、实时叠加和自动曝光占用。
- 试拍独立于星表、解算光学参数和位置设置，不驱动赤道仪，也不把图像计入三点标定。试拍与单点重新解算的停止仅取消当前相机/解算任务。
- 当前失败固定在主预览旁，展示分类、ASTAP 实际输出摘要、可提取的星点数量和就近建议；图像标题旁的诊断按钮可直接展开、选择和复制完整日志。普通 `Focal length` 日志行不再覆盖星点不足原因。未知失败保留未找到匹配星场和原始输出，避免仅凭退出码推断物理原因。
- 错误分类核对 ASTAP 命令行源码中的实际文本，包括 `Only N stars found in image. Abort`、`no star database found` 与 `Not enough memory for binning!`；回归覆盖这些文本与通用退出码组合。
