## 1. 基础与改造前问题

保留现有独立设备连接、协议适配器、按设备设置和暗色/红光视觉样式。改造前（7485d04）壳层点滤镜轮/调焦器等状态会进入 `ACCESSORIES`，器材页再显示覆盖全部设备的 `DeviceTab`；用户本来只想调一个设备，却丢了原任务上下文，还要再找一次入口。

代码依据：[CameraScreen](../app/src/main/java/com/indigo/mobileobservatory/ui/screens/CameraScreen.kt)、[AccessoriesScreen](../app/src/main/java/com/indigo/mobileobservatory/ui/screens/AccessoriesScreen.kt)、[ObservatoryStatusBar](../app/src/main/java/com/indigo/mobileobservatory/ui/components/ObservatoryStatusBar.kt)。

## 2. 目标层级（首批代码已接入）

| 层级 | 内容 | 导航规则 |
|---|---|---|
| 全局状态带 | 每个设备的连接/工作状态 | 保持现有位置；点具体设备打开该设备的快捷面板 |
| 设备快捷面板 | 当前任务所需的少量控制或该设备的连接流程 | 覆盖在原任务上；返回/关闭回到原星图、相机或 EAA，不切一级标签 |
| 器材根页 | 设备清单、连接管理、光路配置 | 用户主动进入“器材”或“管理器材”时显示 |
| 单设备详情 | 完整控制、设备参数、校准和诊断 | 只有当前设备的标题/分区与返回；不再放第二排全设备导航 |

在目标四工作区中，赤道仪完整控制也属于器材详情；星图方向控制和顶部架台快捷面板保持就近可达，不能因减少一级标签而增加日常操作步骤。

已连接滤镜轮默认显示当前滤镜及切换；调焦器显示位置、步长、内外移动与停止。未连接时只展示对应类型的选择/连接，连接后继续当前操作；多个同类型设备准确传递设备身份，不随意切到另一台。

快捷与完整详情复用控制组件及 ViewModel/module 状态；不重建第二套设备连接或控制值。显式“完整控制/更多设置”可进入详情，但返回实际调用处。关闭浮层不隐式断开或取消已提交任务；按住运动控件因手势取消、面板关闭或离开页面失去交互时必须停止。

## 3. 与观测校准的关系

器材页维护设备身份、工作光路、主镜终端和安装配置；星图在需要校准时就地补齐未知项。设备已连接不等于该光路可解算，也不等于手机与镜筒已标定。

架台读取、GOTO、SYNC、跟踪与轴运动观测分别提供能力；不能用连接状态启用整组操作。切镜头、改安装或改模型按 [指向方案](PHONE_PLATE_SOLVE_PLAN.md) 局部失效，不清空所有器材配置。
