# WF-06 / WF-08 辅助相机标定与推镜

本轮新增的是辅助光路到主镜的实际采样及消费路径，手机不是此流程的必需设备。硬件和新手现场验收仍未完成；下面描述代码约束与待验证项，不作为实拍结果。

## 产品路径

- 指向校准的其他选项进入「辅助相机与主镜标定」。辅助相机使用现有导星相机连接角色，可与主相机独立连接。
- 先连接、固定并选择主镜当前是目镜还是相机。曝光与原始格式放在其他选项；不满足原始采集条件时展开相关设置。
- 目镜路径先选亮星并居中，开始采样后再次点击「亮星已居中」，记录真实确认时间。主相机路径独立采样主镜并解析，不使用赤道仪存储坐标代替光学参考。
- 第一个方向拟合安装关系，另一个至少相隔 5° 的实际方向独立验证。只有通过验证后主动保存，失败和取消不覆盖已有关系。真实训练/验证草稿在 ViewModel 中保留；进程重建不伪造丢失的观测。
- 目镜第二点明确选择另一颗亮星，候选按与第一参考方向的球面角距筛选；不沿用第一颗星启用采样。缺少合适亮星时给出短恢复说明。
- 准备和采样阶段均提供缺 D50 的安装入口、主相机就地控制、辅助相机定向重连及导星占用恢复。切去现有解析/导星页再返回会保留第一组样本；若安装或真实设备已经改变，原有版本检查仍要求重新采样。
- 推镜的辅助相机入口消费同一个 PointingRepository。没有安装关系时仅显示辅助光路；主镜轴显示和到位状态都需要有效的辅助→主镜关系。

## 采样和证据

导星、导星标定和辅助参考独占同一路相机。采样前拒绝已运行的导星/标定和未完成的设置写入，不擅自停导星。设置切换先停采，再写入并启动新采集代际。断线、取消及采集代际变化会终止采样；预览取得 SDK 缓冲区之前只复制受限数量的私有帧。

USB 到帧时间是交付时间，不是精确曝光时间。相邻交付区间只用于检测断流和队列覆盖；没有逐帧 SDK 曝光时间时，每帧的保守曝光 bracket 都从本次新采集启动算到该帧交付，并校验单调时钟与 UTC 的一致性。快速排空缓存不能缩窄该不确定度。保留首帧；启动交付延迟时要求重试，不丢弃首帧来掩盖曝光范围内的光学覆盖缺口。

标定样本保存首/中/末三个独立 WCS、对应原始 FITS、全部采样区间的星位/PSF、小时间线和采集代际。正的运动上界包含星位残差、PSF 宽度及质心误差底限；静止架台按真实站点和时间扣除已知地球转动，同时保留曝光时间不确定性。未知匹配或证据未覆盖完整参考区间时拒绝，不以未固定手机 IMU 或人为 0 代替稳定性。

手机时钟仍严格要求 ≤250ms。辅助相机 ≤15s 的合同上限只适用于带完整时间转换、误差预算和独立光学稳定性证据的采样。当前辅助 UI 限制曝光 0.5–5s，并拒绝交付区间超过曝光加 750ms 的样本。未知辅助焦距传 ASTAP 自动视场搜索；规划视场默认 500mm 不冒充确认过的辅助焦距。

## 到位验证

辅助推镜使用 PushToVerificationSession。连续原始星位/PSF观察维护独立运动 epoch；源、布局、掉帧、无可靠星点匹配或观察超时都会清除原验证。

三次 WCS 顺序解析，在前两次完成后才选取最后一张原始帧，PSF 采样持续覆盖解析等待。到位仅接受当前任务和运动 epoch 的票据、实际误差预算、已确认的 PRIMARY 视场及最早可能观测时刻距当前小于 10s。USB clock 上限不会延长年龄限制；没有更精确 SDK 时间源时，整个新采集及解析必须在该保守窗口内完成。采样总时限 40s，保留原票据 45s 上限；自动重试最多五次，超龄或验证失败显示恢复动作。没有 IMU 时提供停稳后快照式推镜，移动时清除到位和当前方向箭头。

## SDK 和内存边界

当前 ToupTek/QHY JNI 使用进程单相机 handle，因此选择/连接前拒绝同 SDK 双相机；进程 lease 防止竞争打开覆盖第一路。ZWO 与 Player One 的实际多相机实现不作此限制。设备物理身份使用驱动限定的真实工厂序列号；未知值使用连接实例 UUID。ToupTek 调用已有 SDK 的 Toupcam_get_SerialNumber，ZWO 只读解析已加载官方库的 ASIGetSerialNumber，不使用可写 ASIGetID。冻结 SDK 二进制不变。

大数组仅保留所需原始帧和一槽私有队列，最多 64 条小 PSF 时间线。采样前以可用 Java 堆检查 6×辅助帧、2×主帧与 32MiB 余量的数组容量估算；异常大的实际帧也在复制前拒绝。这是保护性估算，不是 OOM 保证，不能替代真机原生内存/Java 堆实测。

## 待现场验收

- 实际双相机主镜配对与亮星目镜路径，含不同厂商、匿名设备、断线重连和主辅更换。
- 倾斜安装、镜像、ROI/bin、窄视场静止 Dob 的地球转动及实际推镜后的到位失效。
- 3536×3536 等实际大帧的峰值堆/原生内存、队列丢帧和三次解析耗时；慢解析必须保留过期状态。
- 夜间星点不足、云遮挡、拖线、物理晃动及五次失败后的恢复；新手是否能独立完成两点流程。
