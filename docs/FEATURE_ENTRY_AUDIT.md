# 发布版功能入口复核

2026-10-14，因用户反馈「离线数据库下载、解析和昨天的功能像是消失」复核。基线是 GitHub 最新已发布的 [v1.0.7](https://github.com/Indigo2233/MobileObservatory/releases/tag/v1.0.7)（`907f8d3`，2026-10-10 发布）；另对照 `origin/main / v1.0.8` 标签 `7485d04`。存在 v1.0.8 标签不等于已经发布了 v1.0.8 Release。

## 结论与修正

按用户随后明确要求，**恢复一级「工具」标签和工具页面**，保留工作区内的就近入口。工具页集中提供图像解析（卡片标明 D20/D50）、极轴、导星、影像、实时/后期叠加；两类叠加仍共用已统一的行星/深空工作流。新打开的子页按来源返回，已存在的共享叠加/导星任务继续复用，避免另建一份状态。

**D20/D50 分级解析库与图像解析未被删除，但移除一级工具页后，缺少清晰的替代入口。** `PlateSolveScreen`、`PlateSolveModels` 和 `D50Manager` 的解析库选择、下载、取消、安装状态和删除逻辑与 v1.0.7 一致。本次仅给星表单选控件增加测试标识，没有替换数据库或解析算法。

- 补齐 **星图 → 观测准备 → 解析与离线库**，直接打开已有解析页，首段可选 D20/D50。
- 补齐 **影像 → 图像解析**，与导入、后期叠加并列；不必先导入或打开照片才能选择待解析文件。
- **拍摄 → … → 图像解析** 不再依赖相机连接状态；未连接、连接中或报错时也能准备离线库和处理已有图像。
- 所有快捷入口复用原解析页，按实际来源返回。照片详情的解析动作继续把当前文件带入。

此处 D20/D50 是 ASTAP 的离线解析星表；目标库的 OpenNGC/亮星等目录随应用打包，星图 DSS 图块缓存是另一类资源。不能把三者都称为同一个「下载目标库」，也不能为手机宽场解算要求安装 D20/D50。

## 入口迁移检查

以下为源码入口与回调复核；不冒充各类真实设备的现场验收。

| 线上能力 | 当前入口及结果 |
|---|---|
| D20/D50 星表、下载进度、取消、删除 | 工具 → 图像解析；也可从观测准备 → 解析与离线库进入，原实现保留 |
| 独立文件解析、焦距/像元/传感器与架台坐标提示、结果日志 | 影像 → 图像解析；拍摄「…」与照片详情复用原页 |

| 全局夜视、设置、更新、日志导出/清除、关于 | 顶部全局入口；设备默认值已迁到各自详情 |

| 手机诊断页 | v1.0.7 与当前源码均有页面，但 v1.0.7 没有正常用户入口；不将源码中存在的实验页误报为线上丢失功能 |
