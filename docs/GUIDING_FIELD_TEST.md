# OnStep USB 导星现场验证

2026-10-25 补充：`codex/guiding-phd2` 独立分支进一步实现多步校准、回差测量、曝光控制和工作区改造。新流程与验证边界见 [导星工作区](GUIDING_WORKBENCH.md)；下文描述原先基础闭环，不代表独立分支已经合并 main 或通过现场验收。

本轮代码覆盖 OnStep 赤道仪通过 USB 控制、独立导星相机提供图像的组合。基础流程已有选星、多星匹配、RA/DEC 校准矩阵、算法滤波、死区、修正脉冲与像素 RMS。硬件通信时序、机械回差和实际导星精度仍需现场记录。

## 本轮修改

- 校准和导星修正共用一个任务所有者。停止导星、停止校准、全局 STOP、清除锁定、相机断开及架台断开均取消相关任务；脉冲停止清理完成后才能启动下一项操作。
- 每个已启动或正在发送的脉冲都执行不可取消的物理停止清理。导星路径传播停止通信失败，并尝试全轴停止。
- 设备型号包含 `OnStep` 时，使用有应答的 `:MGd[n]#` 定时导星指令，由控制器负责脉冲截止时间。指令拒绝会报告失败。其余 LX200 / iOptron / SynScan 路径继续使用各自原有运动协议。
- 发脉冲前设置 `:R2#`，采用 1× 导星速率。RA/DEC 校准和后续修正使用相同路径，矩阵以实际测量位移建立。
- 校准中每次运动后等待新的完整曝光，并把处理结果与实际采集回调的帧标识、时间绑定。旧处理队列帧不能借用新回调的时间。
- 加入 SNR、星点半径、峰值饱和过滤，以及多星位移离群点过滤；低质量帧和失配时取消当前修正并重置滤波状态。热像素等被拒绝峰值不占用可用星点的候选名额。
- 校准采用归一化轴夹角检查，允许位移速率较小且条件良好的矩阵；相机/架台重连、画幅改变清除校准。预览标记按源图坐标映射。
- 只读连接在开始校准/导星前给出提示；导星页提供停止校准操作。

OnStep 指令依据：[Command.ino](https://github.com/hjd1964/OnStep/blob/master/Command.ino) 的 `:MGd[n]#`、`:R2#`、`:Qd#` / `:Q#`，以及 [Guide.ino](https://github.com/hjd1964/OnStep/blob/master/Guide.ino) 的速率设置。协议回环测试覆盖四方向、时长、拒绝应答和后续坐标读取；USB 芯片、固件版本及物理运动仍待设备验证。

## 建议的首次测试

1. 完成极轴与机械安装，OnStep 已解除驻停并启用恒星跟踪。在器材中选择 LX200 / OnStep、USB 连接和允许控制，确认赤经赤纬能持续回读。
2. 单独连接导星相机并对焦，曝光先设 1–2 秒，调增益使星点清晰且未饱和。选择高度合适、远离天极且暂时不会过中天翻转的星场。
3. 算法先用 Hysteresis，多星开启，RA/DEC 修正强度先用 0.7，最小修正量先用 0.15 px，反向开关初始关闭。
4. 校准脉冲先用 1200 ms。若提示某轴位移过小，可增至 2000–3000 ms 后重试。界面范围为 300–5000 ms；同一组参数下完成一次有效校准。
5. 开启自动导星，先观察 2–3 分钟，记录 RA、DEC、总 RMS、星点 SNR、两轴校准速率，以及误差是否收敛。持续增大时先停止，再检查校准、方向、回差及机械状态。
6. 验证停止导星、校准中停止和全局 STOP 后均不再产生新的修正脉冲。短暂遮挡导星镜，确认出现丢星/质量不足状态并暂停修正；恢复后检查是否仍匹配原参考星。
7. 基础闭环通过后再同时拍摄主相机图像，观察双相机 USB 供电、帧延迟及星点拖线情况。记录手机、相机、OnStep 固件、曝光、增益、导星镜焦距/像元和测试持续时间。

停止自动导星后，恒星跟踪沿用架台现有状态；全局 STOP 沿用应用现有全局停止行为。定时脉冲只限定当前已接收脉冲的时间，不能代替设备状态验证。

相机旋转、导星光路变化、Bin / ROI 改变、设备重连和过中天后均重新校准。当前尚未自动识别机械旋转和过中天翻转。
