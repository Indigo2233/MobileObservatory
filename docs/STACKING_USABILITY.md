# 叠加功能衔接、新手流程与 EAA 优化

2026-10-13。此记录补充 `STACKING_IMPLEMENTATION.md` 的算法验收。

> 本文记录已实现版本的入口与验证；其中“工具台/文件浏览”是 7485d04 基线代码名称。2026-10-14 的 P0 交互改造按 [交互规范](INTERACTION_GUIDELINES.md) 和 [统一流程](OBSERVING_WORKFLOW_DESIGN.md)，现归属为拍摄 → EAA、影像 → 录像/叠加结果。迁移保留共享素材库、结果返回与科学处理边界；旧验收不自动覆盖新的四工作区导航。

## 检查结论

算法与设备适配的边界基本合理：相机输出明确的线性帧，由 ViewModel 分发到有界队列；
离线叠加使用独立文件源；显示处理与原始累积分离。主要缺口在用户流程和共享状态，
包括系统文件选择器优先、导出后只有路径、相机暂停标记被文件浏览改动、EAA 显示过暗，
以及切换工作区后预设或实时预览不能正确恢复。

本次使用共享 `MediaLibrary` 归集素材，并用明确导航回调衔接相机、叠加和播放器。
算法不依赖 Compose、文件浏览页面或某一个相机 SDK。`CameraViewModel` 仍负责已有设备
协调，没有新增原生图像依赖或改变各设备独立连接的架构。

## 新手操作

### 行星录像后处理

1. 工具台 → 行星后处理叠加 → **我的拍摄录像**。
2. 应用自动列出本软件保存的 SER/PSER，最新在前；点击文件即加载，不复制、不改动源文件。
3. 可先保持完整画面，点击分析质量，再选最佳 25% 或 50%，点击配准并叠加。
4. 选择自然处理或核弹式拉伸，也可点自动显示拉伸；常用亮度直接可调，高级参数按需展开。
5. 保存后点 **查看保存的图片**，或在 **文件浏览 → 叠加结果** 找回 PNG/FITS。
   从查看结果返回会恢复原来的叠加工作区。

没有录像时会解释支持格式，并提供“设置为 SER 并前往相机”。此动作只选择录像格式，
不会自动启动曝光或录像。正在写入的文件会被排除，读取、分析和叠加入口也会再次检查。
导入其他软件的录像使用次要入口“从其他位置导入”。

照片分类明确包括 PNG。播放器保留 MP4 分类，调用系统视频播放器并提供临时只读 URI，
无可用播放器时显示提示。照片及叠加 FITS 从回收站恢复到能被对应分类找到的位置。

### EAA 实时辅助观测

1. 从工具台的 **EAA · 实时辅助观测**，或相机拍摄/预览工具进入。
2. 页面显示准备条件，可直接前往相机连接、对焦和拍摄设置；自动曝光开启或采集暂停时，
   提供明确修复按钮。没有有效相机时不能假启动。
3. 对焦并居中后点击开始，无需先录像。成功开始/继续会退出对焦辅助并显示叠加视图。
   首个有效结果出现前先显示相机单帧；首个有效栈自动适应一次显示亮度。
4. 可切换大图观测，查看累计帧数和有效曝光；暂停保留结果。调焦或移动目标前先暂停，
   开启对焦辅助会切回单帧；更换目标后重置。
5. 一键保存 FITS、PNG 和处理参数。若同时录像，页面会显示录像仍在继续。

首次自动拉伸最多采样 16,384 个有覆盖的线性亮度点，用稳健分位数估计黑白点与中间调；
后续帧不反复改变亮度。手调或显式选择预设优先；需要时可再次手动自动拉伸。
恒定/无效信号会明确拒绝估计。普通处理参数完整保存，因此显示和导出可以重现。
自动拉伸不会改变科学累积、FITS 的原始线性像素、白平衡或饱和度设置。

2026-10-31 的显示修正：新建自然与核弹式预设默认开启自动白平衡，开关位于常用处理区；
自动拉伸的统计使用与渲染一致的背景校正、白平衡后线性亮度。白点以上的亮核进入连续
高光压缩曲线，保留亮度顺序；高光压缩增大时亮部降低。旧参数仍可按原算法重放。
方法和验证范围见 [显示修正记录](STACKING_CALIBRATION.md#display-highlights-white-balance-and-polar-colour-preview-2026-10-31)。

## 修复的状态衔接

- 文件浏览不再设置或清除相机的采集暂停标记。
- 主动暂停相机先暂停叠加。恢复入口只在 SDK 未采集时启动，防止重复采集线程；
  重新连接会同步清除旧暂停标记。
- 部分 SDK 重启后帧号重新计数：仅明确重启采集时清除叠加的去重基准；普通暂停/继续
  仍拒绝重复编号。累计图像、曝光和会话代次保留。
- 各模式记住当前预设；离开离线工作区会恢复主相机页的实时栈渲染。
- 主相机页新增 EAA 状态条与单帧/叠加切换，保留旧结果时不再无提示遮住实况。
- 同一录像写入完成前不可进入分析；其他文件的离线处理与原始录像仍可并行。
- 播放器方向由导航壳统一控制，避免进入/销毁时与子页面争抢方向设置；图像信息对话框
  关闭及返回素材列表也纳入回归。一次复跑出现过 Compose 销毁异常，日志不能确定其
  唯一根因，因此同时消除方向双重管理并强化退出流程验证，不扩大升级整套 UI 依赖。
