# 自动移动采样闭环

2026-10-14。WF-08 的可选 GOTO 采样属于既有指向校准向导；正常两组采样、镜面三组训练加第四组独立验证，及没有架台的手动方式继续存在。

后续同日更新：手机具体镜头与辅助/导星相机现进入同一“指向相机与主镜校准”页面，辅助入口只预选来源，不再从手机“其他方式”另开流程。两种来源均接入主镜相机参考下的可选自动采样，新增源码与本轮证据范围见 [统一校准账本](POINTING_CAMERA_CALIBRATION_DESIGN.md#7-实施与验收账本)。以下测试数字为此前 PR #8 的历史记录，不作为这次新辅助自动采样验证结果。

## 行为与约束

- 主镜相机方式、来源相机固定或可调后已锁紧、手机具体镜头或辅助设备/地点准备就绪、参考源可用时，按真实 GOTO 能力和当前占用提供自动采样；主操作仍为手动拍摄，“自动移动采样”为次操作。辅助来源不要求手机参与。
- 纯规划器只挑当前夜间可见、未来 20 分钟内高度 25–75° 的亮星；当前方向必须已知且在同一范围。第一段和相邻段最大角距 35°，目标间至少相隔 10°，避免高空短弧跨过天顶。
- 镜面前三个目标约束非平行方向，第四目标独立；实际 IMU/光学旋转的可观测性与完整残差仍由真实 fitter 检查，规划几何不代替该检查。
- 确认页列名字、目标高度/方位和范围，只确认一次；明确会移动、不会 SYNC、全程可 STOP，以及独立验证后由用户保存。两分钟内重新检查起始方向和可见性；无可行计划保留手动采样。
- VM 在首次和每次 GOTO 前通过同一个参考预检，检查实际相机打开/采集、D50、科学 RAW/单色及采集代次、自动曝光关闭、预览、设置写入、录像/EAA/快照占用、滤镜轮/旋转器停止、真实 ROI 参考点以及等待窗可容纳的单次曝光。参考采样进入独占采集后再复查；缺库或暂停预览时不先移动。精确居中入口也复用该检查。未配置焦距时仍允许既有 ASTAP 盲解。
- VM 校验架台回读地点/时间、当前协议能力，并逐点重检目标高度、连接/模型版本。架台回读用于运动与范围约束，不作为标定精度真值。
- 整个循环由同一 MountMotionRunner owner 持有。实际 suspend 采集函数的解算、配对或 fitter 异常直接退出循环；STOP/取消中断当前采集并终止后续 GOTO。失败或取消不写入标定仓库。
- 自动采样形成新草稿；只有最后独立验证通过才显示保存动作。保存使用现有真实证据和原子关系/hand-eye 事务。
- 手机与辅助光路共享 `PointingCameraCalibrationScreen` / `PointingCalibrationTask`；旧 `AuxiliaryCalibrationScreen` 兼容路由进入同一任务并预选辅助来源。粗调同轴不触发自动移动，也不能复用为训练/验证样本。

## 自动化证据范围

- `AutomaticCalibrationPlannerTest`：普通两点、镜面四点、夜间/高度/第一步范围、退化与目标不足、方位跨 0°、确认过期及起始变化。
- `AutomaticCalibrationConfirmationInstrumentedTest`：真实 Compose 确认页的目标/范围与提示、取消不启动运动、提交一次、准备状态失效后禁用移动。
- `PrecisionGotoVerificationInstrumentedTest` 的新增 loopback 案例使用真实 module/runner/LX200 TCP：采集阶段保持 STOP、全程没有 SYNC；首次采集异常时不发第二次 GOTO；STOP 取消采集并阻止后续 GOTO。
- `PointingReferencePreflightTest` 覆盖各前置阻塞、厂商 ROI 坐标域及单次曝光范围；`PointingReferencePreflightInstrumentedTest` 使用实际 VM 入口验证缺 D50/暂停预览在查找地点或进入架台任务前拒绝，采样、相机启动/停止均为零。它们不连接物理器材。

这些协议测试使用回环假架台和取消/异常回调，只证明运动任务/交互契约，不算真实标定、镜筒精度或现场碰撞范围验收。

最终构建通过；完整 JVM 917 项通过，含四项 STOP 所有权竞态回归。真实 Module/LX200 回环七项在两构建均通过（`wf-stellarium-protocol-final.log`、`wf-native-accepted-ui.log`），新增“任务正文尚未执行就 STOP，调用方不会挂起”的案例。控制器保留即时急停与协议同步两次 Q，runner 的一次逻辑停止不能在完成前释放任务或误停下一任务。真实架台安全范围、夜间采样与新手验收仍需现场证据。
