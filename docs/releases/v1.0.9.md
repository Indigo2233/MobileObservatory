# Indigo Observatory v1.0.9 — Pre-release

版本：1.0.9 / build 50。日期：2026-10-25。

## 相册单张后期

- 在「影像 → 打开图片 → 后期」调整 LP700 转色、自动/手动白平衡、亮度 EV、黑白场和伽马曲线。
- 按原始分辨率另存 JPG、PNG、FIT；彩色 Bayer 图先去马赛克，FIT 使用 Float32 RGB 三平面，单色素材保留二维结构。
- 处理全程保留浮点精度，FIT 标明显示处理域并记录来源和处理参数；原始输入文件保留。
- 保存按钮常驻、保存后直接查看、取消时清理临时文件；调整参数及保存任务支持屏幕旋转。
- 大幅 FITS 使用受限尺寸预览；全分辨率处理前检查内存和存储空间。

## 构建与验证

- 本地代码和 Android 测试源码编译通过，17 项相关 JVM 回归通过，Lint 0 错误。
- 发布 APK 使用维护者正式签名和旧版证书轮换链，包含 Stellarium 资源，高级序列入口保持隐藏。
- 预发布版本供手动安装验证，稳定更新通道继续指向 v1.0.8 / build 49。

## 待设备验收

Android 界面回归已编译；实际编辑、三种格式保存及重新打开、旋转期间保存、小屏/横屏/大字体、内存峰值及外部软件显示 RGB FITS 仍需设备验收。全厂商相机硬件矩阵和长时间运行覆盖尚不完整；手机端 plate solving 保持实验功能。
