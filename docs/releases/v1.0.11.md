# Indigo Observatory v1.0.11 — build 64

日期：2026-11-21。

## 拍摄上限

- 所有拍摄目标均可自定义拍摄帧数，或按时、分、秒设置拍摄时长。
- 原有固定帧数、固定时长和“无限制”选项继续保留。
- 实时叠加达到上限后暂停并保留累计结果；可在上限菜单或叠加详情中取消上限并继续。
- 上限更新以非阻塞方式交给科学线程，在帧边界应用；重置后的新会话会重新安装当前上限。

## 实时叠加

- 恢复普通工作区的单帧/累计叠加切换，同时保留大图观测界面的紧凑切换控件。
- 达到拍摄上限、普通手动暂停和无效会话原因分别展示，不再把手动暂停误报为达到上限。
- 修复胶囊限制切换控件触控时的背景错位，并完成上限相关定向回归。

## 后期深空叠加

- 选择参考帧与逐帧叠加分别显示进度和帧数，不再把参考扫描与累计合成混为同一阶段。

## 相机连接

- Nikon PTP 会话增加设备复位、端点恢复、超时诊断和一次安全重试，改善 USB 异常后的连接恢复。
