# Indigo Observatory v1.0.12 — build 66

日期：2026-11-26。

## ROI 编辑

- ROI 滑块、预设、重置和偏移调整改为只更新草稿，不再在拖动期间反复停止和重启相机采集。
- 预览画面增加常驻半透明 ROI 框，描边内边界与待应用 ROI 对齐。
- 只有点击“设置当前 ROI”后才向相机应用草稿；应用失败或相机规范化 ROI 后，草稿会同步实际回读值。
- ToupTek 相机的 ROI 偏移支持 2 像素步进，可使用 2、4、6 等非 8 倍数坐标。
- 全画幅操作保留传感器的完整尺寸，兼容硬件 binning 和适配器对齐规则。
