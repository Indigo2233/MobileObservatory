# Indigo Observatory v1.0.9 build 53 Pre-release

日期：2026-10-26。构建号按线上预发布 build 52 加一。

## 解算与极轴校准

- 兼容的 8 位 FITS 在星点不足时自动执行一次 2×2 整数求和，以 UInt16 保存临时解算输入；保留原始文件，成功后将 WCS 坐标映射回原图。处理采用两行缓冲。
- 用户提供的实拍样本在手机原生 ASTAP 中由 4 颗星提升至 7 颗，匹配 15 组四边形并完成盲解；极轴、单图解算和指向校准共用该重试流程。
- 严格校验当前解算的退出码和结果文件，避免读取历史 WCS 后误报成功；失败原因和星点数量按最后一次尝试显示，详细日志保留全部尝试。
- 极轴校准可从应用相册或系统文件中选择图像，修复替换预览时位图提前释放的问题。

## 导星与赤道仪

- 导星界面整合曝光、自动选星、开始导星和停止操作；设置面板提供适合整数及精确数值的输入方式。
- 支持时间设置的连接自动同步日期、时间和 UTC 偏移，并回读校验；同步失败显示原因，只读连接仅查询时间。
- 兼容官方 On-Step 固件名称，修复日期设置应答读取与定时导星脉冲识别。
- FIT/FITS 分享使用文件类型，改善外部应用的接收兼容性。

## 构建与验证

- 本次功能代码已通过 1,218 项 JVM 单元测试、26 项星图脚本测试及 21 项 Android 原生与界面回归；发布提交另执行 Android CI、签名和文件校验。
- 发布包包含 Stellarium 资源，序列入口关闭；使用维护者签名及兼容旧版本的证书轮换链。
- APK、SHA-256、构建信息及 update.json 随发布提供。对应源码为标签 v1.0.9-build53 指向的提交。

## 安装与设备验证

本版本为预发布，供下载 APK 手动安装。正式版更新通道继续指向 1.0.8 build 49。

线上 build 52 及更早版本可升级至本包。已安装本地 build 54–62 测试包的设备受 Android 版本号限制，无法直接覆盖安装 build 53。

OnStep USB 的实际时间同步、太阳 GoTo、现场导星与完整三点极轴流程仍需设备验收；请确认赤道仪经纬度正确。各厂商相机和配件的完整硬件矩阵及长时间运行覆盖尚未完成。
