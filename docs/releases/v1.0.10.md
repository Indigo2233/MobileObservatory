# Indigo Observatory v1.0.10 — build 62

日期：2026-11-03。

## 彩机解析

- ASTAP 求解前把 Bayer FITS 转为同尺寸单通道灰度输入。转换按行读取原始像素，只保留三行源数据和一行输出，不分配 RGB 三通道整幅缓冲。
- 支持 RGGB、GRBG、GBRG、BGGR 四种 CFA 相位；原始 FITS 保持未修改，灰度临时文件在求解结束、失败或取消后删除。
- 两张现场高星数但仍解析失败的图像，在 D20、正确初始坐标和默认参数下改用灰度输入后均成功解算，分别约 0.5 秒和 0.3 秒。
- GOTO 解析临时使用传感器全幅并记录实际捕获 ROI，结束后恢复用户原 ROI；避免先前裁切限制星点和视场。
