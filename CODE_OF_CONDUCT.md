# Code of conduct

Indigo Observatory contributors and maintainers are expected to communicate with
professionalism, technical precision, and respect.

Acceptable participation includes constructive review, reproducible evidence,
clear attribution, respect for user privacy, and patience with hardware-dependent
verification. Harassment, discrimination, threats, deliberate disruption, exposure
of private data, and knowingly false technical claims are unacceptable.

Maintainers may edit or remove abusive content, close disruptive discussions, or
restrict participation when necessary. Report conduct concerns privately through
the repository owner's GitHub profile. Reports will be handled with appropriate
confidentiality and attention to conflicts of interest.

This policy applies to repository discussions, issues, pull requests, reviews,
release coordination, and project-related communication in other venues.
